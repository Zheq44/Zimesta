ZIMESTA ADVANCED WEBSITE
========================

Included files:
- index.html: Full responsive ZIMESTA website
- styles.css: Advanced brand styling, responsive layouts and animations
- script.js: Mobile navigation and WhatsApp enquiry form
- privacy.html: Starter privacy notice
- terms.html: Starter terms of use

PREVIEW
1. Download and extract the ZIP.
2. Open index.html in Chrome, Edge or Firefox.
3. Keep all files in the same folder.
4. An internet connection is needed for the Google Fonts; the site layout itself is stored locally.

WHAT IS NEW
- Dedicated computer skills learning and enrolment enquiry section for primary and secondary school learners, beginners and adults
- Parent/guardian reassurance content covering age-appropriate learning, guidance, online safety and privacy
- School partnership enquiry information
- WhatsApp-based learning enquiry form
- Expanded company story, mission, vision and values
- Five detailed service descriptions
- Audience/customer sectors
- Four-step project process
- CEO leadership section
- FAQ accordion
- Expanded project enquiry form
- SEO description, social sharing metadata and basic organization structured data
- Responsive mobile menu and reduced-motion accessibility support

CONTACT FORM
The form opens WhatsApp with the visitor's enquiry pre-filled. It does not send automatically and does not store submissions on a server.

BEFORE PUBLIC LAUNCH
- Replace the illustrative portfolio artwork with genuine, approved project images.
- Add the official email address and actual website domain when available.
- Confirm the Facebook page URL.
- Add a real CEO portrait if desired.
- Confirm the company's current service availability and adjust descriptions honestly.
- Review the privacy notice and terms against actual business practices.
- Before advertising computer classes, confirm instructors, curriculum, child safeguarding procedures, venue, supervision, fees, schedules and actual availability. Do not claim accreditation or qualifications unless formally obtained.
- Consider adding a custom domain and hosting.

PUBLISHING
Upload all files to a static hosting provider, keeping them together. The homepage file must remain named index.html.
This is a front-end static website. The contact form uses WhatsApp and does not include a backend, database, online payments, user accounts or email delivery.
